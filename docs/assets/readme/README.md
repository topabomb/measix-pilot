# README 媒体

## 来源

- 采集日期：2026-10-16。应用源码基线 `25b6ba1ab`，版本 `0.0.20`，该基线构建的 x86_64 Debug APK。截图保留开发模式标记，不代表商店发行包。
- Android API 36 专用模拟器 `Codex_V5_Final_20261004`；手机窗口 1080 × 2160 / 420 dpi，宽屏窗口 1920 × 1200 / 240 dpi。宽屏截图验证列表与详情布局，不作为物理折叠屏铰链或真机验收证据。
- 使用用户授权的 Orchelm 接入，在默认助手的本域 MCP 设置中启用已经获准的远程工作区。真实调用麦睿菱 Noetral 与 Runcove 的命令、文件工具，没有注入聊天数据库或伪造模型回复。
- 工位 A/B/C 的温度与振动值为人工编写的演示数据。模型在新目录 `pilot-readme-demo-20261016` 生成 CSV、Markdown 与 SVG；从 Pilot 企业文件入口实际打开并检查报告和图表。没有把企业公告、其他业务目录内容或接入凭据放入发布素材。
- `chat-phone.png`、`chat-wide.png` 展示同一会话的现场摘要；`report-wide.png` 展示远程 Markdown 原生预览。截图未经界面合成，使用正常状态栏。
- `walkthrough.mp4` 来自 Android `screenrecord` 连续录屏，仅缩放与 1.25 倍速转码，无音轨；`walkthrough.gif` 为同段视频的低帧率预览。展示文件检查操作，不是完整的模型自主执行录像。
- `pilot-hero.svg` 是工作流示意，不是应用界面。Pilot 标识与蓝色取自 Measix 既有品牌图形；`measix-products.svg` 沿用 Tuck 产品职责图的结构，并突出本仓库 Pilot。两图均为可编辑矢量文件。

## 更新

2. 通过正常界面接入已授权资源。接入材料只用于登录，不写入仓库、脚本、录屏或公开日志。
